# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-10-19

### Added
- Полноценная передача произвольных бинарных и текстовых файлов любого формата (`*.*`) по воздуху через динамики и микрофон.
- Сжатие данных Brotli (RFC 7932) со статическим словарём 120 КБ (сокращение объёма небольших файлов до 2–2.5 раз).
- Модемный уровень на базе `ggwave` с помехоустойчивым кодированием Рида-Соломона (FEC).
- Канальный протокол Stop-and-Wait ARQ с нарезкой на чанки по 52 байта, квитированием (ACK) и до 6 повторных попыток при обнаружении акустического шума.
- Итоговая верификация целостности переданного файла через вычисление CRC32 (`zlib`).
- Раздельные экраны завершения для отправителя («Файл успешно отправлен!») и получателя («Файл успешно получен!»).
- Кнопка «Открыть файл» для мгновенного запуска полученного файла в системной программе по умолчанию (`os.startfile`).
- Кнопка «Показать в папке» для открытия Проводника Windows с выделением файла (`explorer /select`).
- Автоматическая защита от перезаписи файлов в каталоге `received_files/` (добавление счётчика версий `_1`, `_2`).

### Changed
- Оптимизирована скорость акустической передачи: частота кадра настроена на `SAMPLES_PER_FRAME = 512` (символ ~10.6 мс) и активирован протокол `Fastest Audible` (`protocolId = 2`), что ускорило передачу в ~3.5–4 раза.
- Упрощён формат кадрирования до компактного и надёжного вида (`START`, `DATA`, `ACK`, `END`), устранён избыточный оверинжиниринг.

### Fixed
- Исправлено ложное переключение на экран «Файл получен» при отмене передачи или выходе в меню: сигнал `QThread.finished` заменён на строгий сигнал `success`, добавлено отслеживание роли `self.current_role`.
- Устранена ошибка распознавания коротких пакетов `ACK` в C-декодере из-за попадания байтов `\x00` в начало пейлоада.

## [0.1.0] - 2026-10-12

### Added
- Акустический DTMF-модем для передачи данных между ноутбуками через микрофон и динамики.
- Детектирование частот на базе алгоритма Гёрцеля со скользящим окном 60 мс (шаг 20 мс) и кадрированием (`*` и `#`).
- Диалоговое окно выбора файла для отправки изображения через системный файловый проводник.
- Каталог из 12 небесных тел Outer Wilds со скриншотами.
- Автоматическое распознавание отправленного файла по имени и сопоставление с каталогом.
- Фоновые потоки `QThread` для неблокирующей передачи и непрерывного приёма аудио.
